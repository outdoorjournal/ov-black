## Outdoor Voyage: Black

Imagine building an AI-native travel agency for wealthy individuals that is exclusive and invite-only. We have access to wholesale rates on flights, travel experts, and unique inventory that can be customized for adventures that you can't get anywhere else.

Our challenges in the back office are all about scalability and automation, while our challenges in the front office are all about building trust and providing a high-end experience that matches the expectations of our clientele.

We want to use AI at every step of the process, from building a "Voodoo Doll" of the client to understand their preferences and motivations, to creating personalized itineraries that are backed by real local knowledge and real-time information, to automating the booking process and providing a seamless experience for the client.

## Tech Stack

- AI: AWS Bedrock
- Frontend: React Native for mobile app. 
- Mobile: React Native for mobile app. 
- Next.js for backend
- Deploy on Vercel
- Infrastructure:
    - AWS for bedrock and S3 file storage
    - Vercel for hosting and backend
    - Supabase for database and authentication
    - Braintree for payments (already set up)
    - Ratehawk API for hotel inventory
    - Duffel API for flight inventory
    - OutdoorVoyage.com public API for inventory
    - More servies based on needs below
